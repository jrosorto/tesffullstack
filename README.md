# osorto_frontend

Frontend en Angular 21 para gestión de personas. Consume la API de `osorto_backend`.

## Requisitos

- Node.js 18+
- Angular CLI 21+

## Instalación

```bash
cd osorto_frontend
npm install
```

## Ejecución

```bash
ng serve
```

La app corre en `http://localhost:4200`. El backend debe estar activo en `http://localhost:8080`.

## Funcionalidades

- Listado de personas con botones de editar y eliminar
- Formulario para crear nueva persona
- Formulario para editar persona con datos precargados
